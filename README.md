## Ответы на вопросы по функциям PHP

### 1\. `echo` — что делает и чем отличается от `print`?

**Что делает `echo`:** выводит одну или несколько строк в браузер. Это основная функция для вывода HTML и данных на страницу.

**Чем отличается от `print`:**

|`echo`|`print`|
|-|-|
|Может принимать несколько аргументов через запятую|Принимает только один аргумент|
|Ничего не возвращает|Возвращает `1`|
|Работает быстрее|Работает медленнее|
|Используется чаще|Используется реже|

### 2\. Что такое `\_\_DIR\_\_`? Зачем он нужен в путях к файлам?

**`\_\_DIR\_\_`** — магическая константа PHP, которая содержит полный путь к папке, в которой находится текущий PHP-файл.

Она нужна для создания правильных путей к другим файлам независимо от того, из какой папки был запущен скрипт. Например, в файле `includes/counter.php` выражение `\_\_DIR\_\_ . '/../data/visits.txt'` указывает на файл `visits.txt` в папке `data` проекта.

### 3\. Что делает `dirname()`? Приведите пример.

**`dirname()`** возвращает путь к родительской папке указанного пути.

Пример:

```php
$path = '/site/includes/counter.php';
echo dirname($path); // /site/includes
```

В нашем счётчике `dirname($counterFile)` используется, чтобы получить путь к папке `data`.

### 4\. Чем отличаются `is\_dir()` и `mkdir()`? Зачем обе функции нужны в коде счётчика?

* **`is\_dir($path)`** проверяет, существует ли папка по указанному пути. Результат — `true` или `false`.
* **`mkdir($path)`** создаёт новую папку. Также функция позволяет указать права доступа и необходимость создания родительских папок.

В счётчике сначала проверяется наличие папки `data` с помощью `is\_dir()`. Если её нет, `mkdir()` создаёт её. Так программа не пытается создавать папку, которая уже существует.

### 5\. Что проверяет `file\_exists()`? Почему её вызывают перед `file\_get\_contents()`?

**`file\_exists($path)`** проверяет, существует ли файл или папка по указанному пути.

Эту функцию вызывают перед чтением, чтобы убедиться, что файл счётчика уже создан. Если файла нет, программа сначала создаёт его с начальным значением `0`. Иначе попытка чтения отсутствующего файла приведёт к предупреждению и не даст получить нужное значение.

### 6\. Что делают `file\_get\_contents()` и `file\_put\_contents()`? Чем `file\_put\_contents()` отличается от `fopen()` + `fwrite()`?

* **`file\_get\_contents($path)`** читает всё содержимое файла и возвращает его в виде строки.
* **`file\_put\_contents($path, $data)`** записывает данные в файл. Если файл уже существует, его содержимое по умолчанию заменяется; если файла нет, он создаётся.

`file\_put\_contents()` позволяет записать данные одной командой. При использовании `fopen()` и `fwrite()` файл нужно отдельно открыть, записать в него данные, а затем закрыть с помощью `fclose()`. Такой способ даёт больше контроля над работой с файлом, но требует больше кода.

### 7\. Зачем нужно `(int)` перед `file\_get\_contents()`?

**`file\_get\_contents()`** возвращает содержимое файла как строку. Например, число `15` сначала будет прочитано как строка `'15'`.

Приведение **`(int)`** преобразует эту строку в целое число `15`. После этого значение можно увеличивать с помощью `$visits++` и сохранять обратно в файл.

### 8\. Чем `require\_once` отличается от `include`? Когда что использовать?

Обе конструкции подключают и выполняют код из другого PHP-файла.

* **`include`** при отсутствии файла выдаёт предупреждение, но выполнение программы обычно продолжается.
* **`require\_once`** при отсутствии файла вызывает критическую ошибку. Кроме того, файл с этой конструкцией подключается не более одного раза за выполнение скрипта.

`require\_once` удобно использовать для обязательных частей сайта, без которых страница не сможет нормально работать, например для общей шапки или файла с важной логикой. `include` можно использовать для необязательных частей страницы.

### 9\. Что делают `date('Y')` и `date('d.m.Y H:i')`? Что будет, если не задать часовой пояс?

Функция **`date()`** возвращает дату или время в заданном формате.

* **`date('Y')`** возвращает год из четырёх цифр, например `2026`.
* **`date('d.m.Y H:i')`** возвращает дату и время в формате день.месяц.год часы:минуты, например `19.11.2026 14:30`.

Если часовой пояс не задан в программе или настройках PHP, будет использоваться часовой пояс по умолчанию, установленный в конфигурации PHP. Из-за этого время на сайте может отличаться от местного. В нашем проекте часовой пояс задаётся командой `date\_default\_timezone\_set('Europe/Moscow')` в файле `header.php`.

### 10\. Что такое `$\_COOKIE`? Как с её помощью считать уникальные посещения?

**`$\_COOKIE`** — суперглобальный массив PHP, в котором находятся cookie, отправленные браузером вместе с запросом к сайту. Cookie — небольшие данные, которые сайт может сохранить в браузере пользователя на определённое время.

Чтобы приблизительно считать уникальных посетителей, при первом посещении можно проверить, есть ли специальная cookie. Если её нет, сайт устанавливает cookie с помощью `setcookie()` и увеличивает отдельный счётчик уникальных посещений. При следующих запросах браузер отправит сохранённую cookie, поэтому повторно увеличивать этот счётчик не нужно.

Пример проверки:

```php
// Этот код нужно выполнить до вывода HTML.
if (!isset($\_COOKIE\['visitor'])) {
    setcookie('visitor', '1', time() + 365 \* 24 \* 60 \* 60, '/');

    // Здесь увеличивается отдельный счётчик уникальных посетителей.
}
```

Cookie начинает приходить в `$\_COOKIE` со следующего запроса браузера после её установки. Такой способ считает уникальные браузеры, а не гарантированно уникальных людей: один человек может пользоваться несколькими устройствами или браузерами, а cookie можно удалить.
