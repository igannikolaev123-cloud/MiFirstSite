ПРОЕКТ «МОИ ФИНАНСЫ — ВАРИАНТ 1»

Файлы проекта:
- index.html  — разметка страницы;
- style.css   — внешний вид страницы;
- script.js   — загрузка JSON, фильтрация, сортировка и подсчёт итогов;
- data.json   — исходные данные варианта 1 (100 операций).

КАК ЗАПУСТИТЬ ПРОЕКТ В VS CODE

1. Распакуй архив в отдельную папку.
2. Открой VS Code и выбери File → Open Folder (Файл → Открыть папку).
3. Выбери папку «Финансы_Вариант_1».
4. Открой Terminal → New Terminal (Терминал → Создать терминал).
5. Убедись, что терминал открыт именно в папке проекта.
6. Выполни команду:

   python -m http.server 8000

   Если команда python не сработает в Windows, попробуй:

   py -m http.server 8000

7. Не закрывая терминал, открой браузер и перейди по адресу:

   http://localhost:8000/

ВАЖНО

Не открывай index.html двойным щелчком через проводник. Для загрузки data.json используется fetch(),
поэтому страницу нужно открывать через локальный сервер.
Чтобы остановить сервер, вернись в терминал и нажми Ctrl + C.

ЧТО РЕАЛИЗОВАНО

- загрузка 100 операций из data.json с помощью fetch();
- фильтрация по типу операции;
- фильтрация по категории;
- фильтрация по начальной и конечной дате;
- сброс всех фильтров;
- сортировка по дате, типу, категории, описанию и сумме;
- подсчёт доходов, расходов, баланса и количества отображаемых операций.
